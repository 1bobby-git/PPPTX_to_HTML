# Windows 실행 파일 사용법

PPTX를 선택하고 HTML로 저장하는 로컬 프로그램입니다. **Node.js, PowerPoint 또는 CMD 명령어 입력이 필요하지 않습니다.** 변환 엔진과 실행 환경을 배포 파일에 함께 포함합니다.

## 시작하기

1. Windows x64용 Desktop ZIP을 내려받아 **압축을 모두 풉니다.**
2. 압축을 푼 폴더에서 **`PPPTX_to_HTML.exe`**를 더블클릭합니다.
3. **파일 선택**으로 PPTX를 고릅니다.
4. 필요한 옵션을 지정하고 **변환**을 누릅니다. 일반 Office 암호 문서는 지원되는 형식에 한해 암호를 입력해 변환할 수 있습니다.
5. 완료 후 **HTML 저장**으로 저장 위치를 선택합니다.

EXE와 같은 폴더에 있는 DLL·`resources`·`locales` 등을 함께 보관해 주세요. EXE 하나만 다른 폴더로 복사하면 실행되지 않습니다. 별도의 설치 프로그램이나 자동 업데이트는 사용하지 않습니다.

## 지원 범위

- Windows x64용 포터블 프로그램입니다.
- 파일은 이 PC에서 읽고 변환합니다. 변환을 위해 문서를 서버로 업로드하거나 PowerPoint를 실행하지 않습니다.
- 저장된 HTML은 브라우저에서 열 수 있으며, 원본 PPTX나 이 프로그램을 다시 실행하지 않아도 볼 수 있습니다.
- 글자, 이미지, 도형, 표, 지원되는 차트와 슬라이드 이동을 처리합니다. 글꼴과 일부 복잡한 서식·효과는 원본과 다르게 표시될 수 있습니다.
- 슬라이드 범위와 숨김 슬라이드 포함 여부를 선택할 수 있습니다.

## 회사 보안 문서

회사 DRM 문서는 해당 보안 프로그램이 이 실행 파일의 문서 읽기와 HTML 저장을 허용해야 처리할 수 있습니다. **EXE 형식이라는 이유만으로 NASCA 등의 DRM 문서를 변환할 수 있게 되는 것은 아닙니다.**

파일 형식을 읽을 수 없다는 메시지는 DRM을 확정한 진단이 아닙니다. 다른 보호 형식, 지원하지 않는 문서 구조 또는 불완전한 파일일 수도 있습니다. 회사의 공식 연동과 허용 정책이 적용되지 않은 DRM 문서는 현재 지원을 보장하지 않습니다.

## 개발자용 배포 생성

다음 명령은 배포 파일을 만드는 개발자만 사용합니다. 일반 사용자는 위의 EXE를 실행하면 됩니다.

```bash
npm ci --ignore-scripts --no-audit --no-fund
node scripts/package-desktop.cjs --platform win32 --arch x64
```

Electron **45.0.0**과 내장 Node.js **24.22.0**을 사용합니다. 공식 배포 URL·크기·SHA256은 `desktop/runtime.json`에 고정되어 있으며, 다운로드한 실제 파일의 해시를 확인한 후 패키징합니다. 내려받은 공식 ZIP을 `--runtime-archive FILE`로 지정할 수도 있습니다.

`--output-dir DIR`는 결과를 만들 상위 폴더를 지정하고, `--unpacked-only`는 ZIP 생성 없이 실행 폴더까지만 만듭니다. `--platform linux --arch x64`는 개발 중 Linux 실행 검증용 배포를 생성합니다.

각 배포의 `DESKTOP-MANIFEST.json`에 앱·Electron·Node·변환 엔진 버전, 공식 런타임 해시와 포함된 production 패키지를 기록합니다. 라이선스와 변환 엔진의 출처 고지도 함께 포함합니다.
