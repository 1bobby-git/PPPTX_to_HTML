# v1.6.0 · Windows 실행 파일 추가

PPTX를 선택하고 HTML로 저장하는 Windows x64용 포터블 앱을 추가했습니다. Node.js 설치나 CMD 명령어 입력이 필요 없습니다. PowerPoint·LibreOffice를 실행하지 않고, 문서를 서버로 업로드하지 않습니다.

## 일반 사용자

1. **PPPTX_to_HTML_Desktop_v1.6.0_win32-x64.zip**을 내려받아 압축을 모두 풉니다.
2. **PPPTX_to_HTML.exe**를 더블클릭합니다. EXE 옆 DLL·resources·locales도 함께 보관해 주세요.
3. **파일 선택 → HTML로 변환 → 미리보기 → HTML 저장** 순서로 사용합니다.

슬라이드 범위·숨김 슬라이드 포함·제목·지원되는 Office 문서 열기 암호를 설정할 수 있고, 변환을 취소한 뒤 다시 실행할 수 있습니다. 저장한 HTML은 일반 브라우저에서 독립적으로 열 수 있습니다.

## 포함 파일

| 파일 | 용도 |
| --- | --- |
| `PPPTX_to_HTML_Desktop_v1.6.0_win32-x64.zip` | Windows x64 실행 파일과 실행 환경·변환 엔진을 포함한 포터블 앱 |
| `index.html` | 브라우저에서 직접 변환하는 기존 오프라인 단일 HTML |
| `PPPTX_to_HTML_Native_v1.6.0.zip` | 운영자·자동화용 CLI와 웹 서비스. Node.js는 별도로 필요 |
| `SHA256SUMS.txt` | 배포 파일의 SHA256 |

## 변경 및 검증

- 브라우저·CLI와 동일한 `2.1.0-ppptx.1` 변환 엔진을 재사용합니다. 변환 엔진을 중복 추가하지 않았습니다.
- EXE가 원본 경로를 직접 읽고 내장 작업 스레드에서 변환합니다. 별도 `node.exe`나 Office 프로세스를 실행하지 않습니다.
- 로컬 파일·저장 대화상자를 제공하고, 문서 미리보기를 앱의 파일 접근 기능에서 격리합니다.
- WebKit에서 슬라이드 크기를 맞출 때 발생하던 ResizeObserver 반복 오류를 수정하고, 한 장씩 보기에서 창 높이 변경도 반영합니다.
- 공식 Electron 45.0.0·내장 Node.js 24.22.0 런타임을 크기·SHA256 확인 후 포함합니다.
- 저장소 밖으로 복사한 실제 Windows 배포 앱에서 일반 PPTX·Office 암호·범위·숨김·취소/재시도·미리보기·HTML 저장을 검사합니다.
- Windows·macOS·Linux의 CLI·웹 흐름, Firefox·WebKit의 오프라인 흐름이 모두 통과한 뒤 이 배포를 게시합니다.

## 회사 DRM 문서

EXE 형식만으로 NASCA 등의 보호를 해제하지는 않습니다. 회사 보안 프로그램이 이 실행 파일에 평문 PPTX 읽기와 HTML 저장을 허용해야 처리할 수 있습니다. 실제 NASCA 문서의 성공 여부는 아직 검증되지 않았습니다. 알 수 없는 파일 형식을 확장자 변경이나 DRM이라고 단정하지 않습니다.

글꼴·복잡한 서식·일부 차트·SmartArt·애니메이션 등은 원본과 차이가 날 수 있습니다. Windows 포터블 앱 제공이 모든 OS의 EXE 지원이나 모든 PowerPoint 기능의 완전한 재현을 뜻하지는 않습니다.
