# v1.6.2 · 버전 표시와 다운로드 안내 수정

v1.6.1을 배포한 뒤에도 화면과 안내 문서가 이전 버전을 가리키던 문제를 고쳤습니다. 변환 엔진, 암호 문서 처리, 보안 설정은 v1.6.1과 같습니다.

- 단일 `index.html`과 웹 서비스 화면 아래쪽에 실제 버전(v1.6.2)을 표시합니다. v1.6.1 화면에는 v1.6.0으로 표시되었습니다.
- README와 Native CLI 안내의 최신 버전, 다운로드 링크, ZIP 파일 이름을 v1.6.2로 맞췄습니다. 이전 안내는 보안 보강 전인 v1.6.0 다운로드를 가리켰습니다.
- 패키지·잠금 파일·데스크톱 앱 버전, 화면 표시 버전, README 다운로드 안내가 서로 다르면 `npm test`가 실패하도록 검사를 추가했습니다.

기존 v1.6.0·v1.6.1 다운로드를 덮어쓰지 않습니다. 새 `index.html`, `PPPTX_to_HTML_Native_v1.6.2.zip`, `PPPTX_to_HTML_Desktop_v1.6.2_win32-x64.zip` 및 `SHA256SUMS.txt`를 사용해 주세요.

## 실행 환경에 남은 제한

v1.6.1의 안내가 그대로 적용됩니다. Windows 앱은 공식 Electron 45.0.0 / 내장 Node.js 24.22.0을 사용하며, 이 배포로 내장 런타임이 바뀌지는 않습니다. 회사 DRM 해제, 모든 PowerPoint 기능의 완전 재현 또는 모든 운영 환경의 안전을 보장하는 업데이트는 아닙니다.
