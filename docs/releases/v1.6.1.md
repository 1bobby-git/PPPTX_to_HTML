# v1.6.1 · 오프라인 브라우저 암호화 의존성 보안 보강

오프라인 `index.html`에서 문서 복호화에 사용하지 않는 elliptic 서명·ECDH 코드를 제거했습니다. 기존 SHA/HMAC/AES 구현과 Office 암호 문서 처리는 유지합니다. 금지된 서명 패키지가 다시 포함되면 빌드를 중단합니다.

- 개발용 PPTX 생성기의 image-size를 2.0.4로 고정했습니다.
- 운영 의존성 감사는 0건입니다. Browserify 개발 도구의 elliptic 관련 낮은 위험 경고 4건은 공급업체 수정이 없어 남아 있으며, 해당 코드가 배포 HTML에 포함되지 않도록 차단합니다.
- 빌드 결과의 줄바꿈을 정규화해 Windows와 다른 플랫폼에서 같은 스크립트·스타일을 생성합니다.
- 정상 문서와 Agile/Standard 암호 문서, 잘못된 암호, 변조 거부, 외부 통신 차단 및 브라우저·CLI·웹·데스크톱 호환성 검사를 통과한 파일만 게시합니다.

기존 v1.6.0 다운로드를 덮어쓰지 않습니다. 새 `index.html`, `PPPTX_to_HTML_Native_v1.6.1.zip`, `PPPTX_to_HTML_Desktop_v1.6.1_win32-x64.zip` 및 `SHA256SUMS.txt`를 사용해 주세요.

## 실행 환경에 남은 제한

네이티브 CLI·웹 서비스는 보안 업데이트된 Node.js 22.23.4 또는 24.22.1 이상에서 실행해 주세요. 외부 Node.js를 업데이트해도 Windows 포터블 앱에 내장된 Node.js가 바뀌지는 않습니다.

Windows 앱은 공식 Electron 45.0.0 / 내장 Node.js 24.22.0을 그대로 사용합니다. 현재 공식 안정판에 Node.js 24.22.1이 포함된 후속 버전이 없어 내장 런타임 업데이트는 대기 중입니다. 이 배포를 모든 Node.js 보안 문제가 해결된 버전이라고 표현하지 않습니다.

회사 DRM 해제, 모든 PowerPoint 기능의 완전 재현 또는 모든 운영 환경의 안전을 보장하는 업데이트는 아닙니다.
